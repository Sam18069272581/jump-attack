# Jump Attack · 手机端

Expo（SDK 57）+ React Native，iOS 优先。数据存在手机本地 SQLite。

用 SDK 57 是为了和 iPhone 上 Expo Go 支持的版本一致（2026-10 实测）。Expo Go 每个版本只支持一个 SDK；它更新后如果提示版本不匹配，要把项目一起升级。

## 现在能做什么

- **跳跃测试**：CMJ、SJ、单腿 CMJ。用 120/240 fps 视频（App 内录像，或用 iPhone 慢动作拍好后导入），逐帧标出起跳帧和落地帧，按 h = g·t²/8 算跳高；每次测试可做多次，取最好成绩。
- **力-速度曲线**（跳跃测试 → 找短板）：史密斯机负重蹲跳 4 级（约体重的 0、25%、50%、75%），每级跳 2–3 次，录像或手填跳高，记在单独的「负重蹲跳」项目下，不影响 SJ 历史。按 Samozino 简易法算 F0、v0、Pmax，并和同样功率下跳得最高的曲线比，得出 FV%（100 = 均衡，低于 90 偏缺力量，高于 110 偏缺速度），给出每周 6 个下肢练习的配比和 VBT 速度损失上限。只是建议，不改训练计划。需要先在「我的」填体重、腿长和 90° 下蹲时大转子离地高度。
- **DJ 跳深 · 找最佳箱高**（跳跃测试 → 找短板）：从 20 cm 起逐级加高箱子，录像逐帧标出触地、起跳、落地三帧（或手填触地时间和跳高），算每个箱高的 RSI（跳高 ÷ 触地），找出 RSI 最高的箱高；触地超过 250 ms 会提示。
- **评估**：和自己的历史比较，超过「最小有意义变化」（0.2 × 个人标准差）才算真进步；CMJ 比近期基线低 5% 以上提示疲劳。
- **历史**：每个指标的趋势图和逐次记录。
- **训练计划**：从模板生成每周训练（「垂直弹跳 · 4+1 周期」每周 3 练，或「保持 · 每周 2 练」循环），自选训练日。
- **今日训练**：练之前测一次 CMJ。CMJ 比近期均值低 5% 以上，或当天 HRV 低于自己 7 天基线（静息心率偏高加睡眠不足也算），就自动减量（取消最大强度练习，其余组数约减 30%、RPE 降 1），并写明改了什么、为什么。逐组打勾记录次数、重量和 RPE，练完看训练报告。
- **自动调整**：最近 3 次测量都有疲劳信号时，训练页建议插入一周减量（组数约 −40%、RPE −1.5），之后的计划整体顺延一周。VBT 估算出深蹲 1RM 后，训练里的杠铃后蹲按「次数 + RPE」自动推荐重量（28 天内的估算才用）。
- **速度**：10 / 30 / 50 / 100 m 和自定义距离冲刺。慢动作录像逐帧标起跑帧和冲线帧算时间，也可以用光电门或秒表计时后手动输入。
- **VBT**：深蹲、高翻和高拉（地面 / 悬垂 / 发力位）、深蹲跳。逐组记重量、次数和平均速度（测速设备读数，或慢动作录像按杠铃行程 ÷ 时间算），标出速度区间，同重量下速度掉 20% 提示停组；两个以上重量就拟合载荷-速度曲线，深蹲按 0.3 m/s 估算 1RM，并给出每个速度区间对应的重量。
- **灵活度**：踝背屈、髋内外旋、直腿抬高、托马斯测试、胸椎旋转、肩屈曲，左右各记一次，左右差 ≥ 10% 标橙。角度可以把手机贴在肢体上「量角」，每项都写了测法。
- **恢复**：每天早上记 HRV、静息心率、睡眠、呼吸频率（从 iPhone「健康」App 或手表上看），和自己 7 天基线比，给出「良好 / 一般 / 疲劳」，并参与训练的自动减量。
- **体能耐力**：VO2max 用 Yo-Yo 间歇恢复测试 1 级或 Cooper 12 分钟跑（按距离估算），反复冲刺能力用 RSA 6×(20+20 m)、间休 20 秒（看平均时间和递减百分比）。只要标志桶和手机，App 负责报起跑音、折返音和中文语音，RSA 可以由同伴在手机上停表，也可以手动填测速门成绩。
- **我的**：测试对象切换和档案（体重、站立摸高）。

首页所有板块都能用了。历史页按板块列出每个有记录的指标。

## 装到 iPhone 上（不用 Xcode）

用 **Expo Go** 运行：Intel Mac、Apple 芯片 Mac、Windows 电脑都行，不用 Xcode，也不用付费的开发者账号。

1. iPhone 上从 App Store 安装 **Expo Go**。
2. 电脑上安装 **Node.js**：[nodejs.org](https://nodejs.org) 下载 LTS 安装包。Mac 系统版本较旧、装不上时，改装 22 版本。
3. 下载代码：打开 https://github.com/Sam18069272581/jump-attack/archive/refs/heads/main.zip ，Safari 会自动解压到「下载」里的 `jump-attack-main` 文件夹。会用 git 的话：

   ```sh
   git clone https://github.com/Sam18069272581/jump-attack.git
   ```

4. 打开「终端」（Windows 用 PowerShell），输入 `cd `（后面带一个空格），把代码里的 `mobile` 文件夹拖进窗口，回车。然后：

   ```sh
   npm install
   npm start
   ```

5. 终端里会出现二维码。手机和电脑连同一个 Wi-Fi，用 iPhone 自带相机扫码，点弹出的提示，App 就在 Expo Go 里打开了。扫码后连不上（比如网络有隔离）时，按 Ctrl+C 停掉，改用 `npx expo start --go --tunnel`。

用的时候电脑上的终端要开着。测试记录存在手机上，下次 `npm start` 再扫码打开还在。

### 在 Expo Go 里怎么测

Expo Go 不带高帧率相机模块，所以先用 iPhone 自带相机的慢动作拍，再导入 App：

1. 设置 → 相机 → 录制慢动作，选「1080p，240 fps」。
2. 手机放稳在地面或三脚架上，镜头对准脚踝，距离约 1.5 米。相机切到「慢动作」，起跳前 2 秒开拍，落地站稳 2 秒后再停。
3. App 里：跳跃测试 → 选项目 → 从相册导入视频 → 逐帧标记起跳帧和落地帧。
4. 如果逐帧页显示视频只有 30 fps，把「拍摄帧率」选成 240。慢动作导出后每一帧仍然是 1/240 秒，App 会按 240 计算。

### 速度和 VBT 录像

- 冲刺：三脚架放在跑道侧面，起点线和终点线都要在画面里（10 m 大约站 8–10 米远）。逐帧标「起跑帧」（身体第一次动）和「冲线帧」（躯干越过终点线）。30 m 以上一台手机拍不全时，用光电门或秒表计时后选「手动输入成绩」。
- 力-速度曲线：手机拍法和 CMJ 一样。先在页面上选好这一跳的负重（含杠铃杆），再点「录像测这一跳」。蹲到膝关节 90° 停 2 秒，不往下顿直接跳。
- DJ 跳深：手机放侧面，箱子边缘和落地点都要在画面里。从箱子上迈出落下，一着地就尽快弹起；逐帧标「触地帧」「起跳帧」「落地帧」。
- VBT：在 VBT 页先填重量和杠铃行程（杠铃最低点到最高点的距离，卷尺量一次），点「录像测速」，从侧面拍一组，逐帧标出向心开始和结束。有测速设备的话直接填平均速度更准。

### 体能耐力测试

测之前把手机音量开大，静音键开着也会响，有音乐会自动压低。测试进行中屏幕不会自动锁。Yo-Yo 和 RSA 都是 20 m 往返，手机放在起点旁边就行。

### 以后：在 App 里直接录 240 fps

需要装开发版 App（含 react-native-vision-camera），二选一：

- **不用 Mac**：加入 Apple Developer Program（每年 99 美元），用 EAS 云端编译后装到手机上，之后用 `npm run start:dev` 连接：

  ```sh
  npx eas-cli@latest build --profile development --platform ios
  ```

- **有能装最新 Xcode 的 Apple 芯片 Mac**：iPhone 打开开发者模式，用数据线连上后运行 `npx expo run:ios --device`（免费 Apple ID 即可，7 天后要重新装一次）。

开发版和 Expo Go 用的是同一套代码：App 发现自己在 Expo Go 里，就显示「慢动作拍 → 导入」页面，否则打开 App 内相机。

## 开发

```sh
npm test            # 单元测试（计算公式、评估、数据库、Expo Go 兼容）
npm run typecheck
npm run lint
```

目录：

| 路径 | 内容 |
|---|---|
| `src/app/` | 页面（Expo Router，每个文件一个路由） |
| `src/domain/` | 纯计算：跳高、RSI、SWC、疲劳判断、计划展开和减量规则（`plan.ts`、`templates.ts`），带单元测试 |
| `src/db/` | SQLite 表结构迁移和查询 |
| `src/components/` | 图标、按钮、趋势图；`capture/` 是录像页（App 内相机和 Expo Go 的导入页） |
| `src/theme/` | 颜色和字体（取自设计稿） |
